## Skills demonstrated across these projects

- **Embedded/firmware:** C (ATmega16 bare-metal), STM32, register-level peripheral configuration
  (GPIO, USART, Timers/PWM, ADC, interrupts)
- **Robotics & control:** path planning (A*), kinematics/Jacobian analysis, PID/fuzzy/ANFIS control
  design and tuning (Ziegler-Nichols), sensor fusion (mmWave radar, ultrasonic)
- **Industrial automation:** Siemens TIA Portal ladder logic, analogue I/O scaling/calibration,
  PLC-based control of motors, sensors, and safety interlocks
- **Simulation/modelling:** MATLAB, Simulink, Simscape, MATLAB Fuzzy Logic Toolbox, ARTE Robotics
  Toolbox
- **Mechanical design:** Autodesk Inventor, drivetrain/gearbox sizing, power/torque budgeting, FEA
- **PCB/electronics:** KiCad schematic and PCB layout, CAN bus integration
- **Building services:** compliance auditing against AS/NZS standards and the NCC, Building
  Management Systems (BACnet, Modbus, KNX, DALI)
